## Version Format

- **Major** (X.0.0): Breaking changes
- **Minor** (0.X.0): Yangi funksiyalar (backward compatible)
- **Patch** (0.0.X): Bug fixes va kichik o'zgarishlar

## Categories

- **Added**: Yangi funksiyalar
- **Changed**: Mavjud funksiyalardagi o'zgarishlar
- **Deprecated**: Tez orada o'chiriladigan funksiyalar
- **Removed**: O'chirilgan funksiyalar
- **Fixed**: Bug fixes
- **Security**: Xavfsizlik o'zgarishlari
