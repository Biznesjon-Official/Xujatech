# 🔐 Localtunnel Parol

## Parolni olish:

1. **Kompyuterda** quyidagi URL'ni oching:
   ```
   https://loca.lt/mytunnelpassword
   ```

2. Sahifada **IP manzilingiz** ko'rsatiladi - bu sizning parolingiz

3. Telefondan ochganda shu parolni kiriting

## Yoki:

Sahifada **"Click to Continue"** tugmasini bosing - avtomatik o'tadi

## Muqobil yechim:

Agar parol muammosi bo'lsa, ngrok ishlatishingiz mumkin (lekin registratsiya kerak):

1. https://dashboard.ngrok.com/signup - ro'yxatdan o'ting
2. Authtoken oling
3. Quyidagi buyruqni ishga tushiring:
   ```
   ngrok config add-authtoken SIZNING_TOKEN
   ngrok http 3002
   ```
