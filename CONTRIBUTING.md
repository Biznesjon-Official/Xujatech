# Contributing to XUJATECh POS

XUJATECh POS loyihasiga hissa qo'shganingiz uchun rahmat! 🎉

## 🤝 Qanday Hissa Qo'shish Mumkin

### 1. Bug Report (Xato Xabari)

Agar xato topsangiz:

1. [Issues](https://github.com/your-username/xujatech-pos/issues) bo'limiga o'ting
2. "New Issue" tugmasini bosing
3. Xato haqida batafsil ma'lumot bering:
   - Xato tavsifi
   - Qayta ishlab chiqarish qadamlari
   - Kutilgan natija
   - Haqiqiy natija
   - Screenshot (agar kerak bo'lsa)
   - Muhit (OS, Browser, Node version)

### 2. Feature Request (Yangi Funksiya)

Yangi funksiya taklif qilish uchun:

1. Avval [Issues](https://github.com/your-username/xujatech-pos/issues) da mavjudligini tekshiring
2. Yangi issue yarating
3. Funksiya haqida batafsil yozing:
   - Nima uchun kerak?
   - Qanday ishlashi kerak?
   - Foydalanish holatlari

### 3. Pull Request

Kod yozish uchun:

1. Repository ni fork qiling
2. Yangi branch yarating:
   ```bash
   git checkout -b feature/yangi-funksiya
   ```
3. O'zgarishlarni qiling
4. Commit qiling:
   ```bash
   git commit -m "feat: yangi funksiya qo'shildi"
   ```
5. Push qiling:
   ```bash
   git push origin feature/yangi-funksiya
   ```
6. Pull Request yarating

## 📝 Kod Standartlari

### TypeScript/JavaScript

- TypeScript ishlatamiz
- ESLint rules ga rioya qiling
- Prettier bilan format qiling
- Meaningful variable names
- Comments yozing (kerak bo'lganda)

### Commit Messages

Conventional Commits formatidan foydalanamiz:

```
feat: yangi funksiya qo'shildi
fix: xato tuzatildi
docs: hujjatlar yangilandi
style: kod formatlash
refactor: kod refaktoring
test: testlar qo'shildi
chore: build yoki dependencies
```

### Code Review

Barcha PR lar code review dan o'tadi:

- Kod o'qilishi oson bo'lishi kerak
- Testlar yozilgan bo'lishi kerak (agar kerak bo'lsa)
- Documentation yangilangan bo'lishi kerak
- Breaking changes bo'lmasligi kerak (yoki batafsil tushuntirilgan)

## 🧪 Testing

```bash

# Frontend tests
cd desktop
```
